# Docs MCP Onboarding

Onboard into `ai.pharos.xyz` using only Developer Docs MCP. No search engine, no blog, no Discord. The output is the log.

| Requirement | How |
|---|---|
| Step-by-step log | Each step prints what I tried, the exact question, and the Docs MCP answer with source links |
| At least 3 gaps | A step is a gap when the reply is missing, wrong, or says the page is not there. The exact query is repeated under Gaps |
| A fix per gap | Under each gap: what that docs page should have said. The fix is labeled as a suggestion, not as a quote from the docs |
| What ran at the end | The log closes with what the useful answers actually unlocked (Chain MCP URL, official USDC). I do not claim I opened ai.pharos.xyz if the docs never said how |

```bash
npm run onboard -- --lang en
```
